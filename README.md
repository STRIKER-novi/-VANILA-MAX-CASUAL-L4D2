PRESIONA <>CODE es el boton azul o verde a la derecha y en al ultima opcion descargar ZIP y se descargaran todos los plugins

Lleva el archivo descargado a tu L4D2 que seria "C:\Program Files (x86)\Steam\steamapps\common\Left 4 Dead 2" y ahi dentro descomprimes los archivos

Una vez instalado los 2 archivos.rar entras a "C:\Program Files (x86)\Steam\steamapps\common\Left 4 Dead 2\left4dead2\addons\sourcemod" y abre el archivo llamado "README-LEEME-tarado.txt" y sigue las intrucciones para poder ser Admin 

Instalar todo los archivos COMPRIMIDOS .rar y leer los txt 
no tarda mucho

!!! Para activar el sourcemod con sus plugins NO OLVIDES PONER "-insecure" en tus parametros de lanzamiento del L4d2 este parametro tambien impedira que te unas a otras partidas y solo podras jugarla en tu sala de HOST LOCAL
